# LinkedIn Upload Guide

1. Start a new LinkedIn post.
2. Select all four numbered PNG files together, in order:
   `01-cover.png`, `02-dashboard.png`, `03-reporting.png`, `04-features.png`.
3. Paste the text from `LINKEDIN_CAPTION.txt`.
4. Confirm that `01-cover.png` is the first image.
5. Publish.

The screenshots use a saved authorized local-network scan. The raw source
captures are in `raw-screenshots/` if you prefer a single unedited screenshot.
