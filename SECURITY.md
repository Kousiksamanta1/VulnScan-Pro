# Security Policy

## Reporting

Do not publish a vulnerability that could enable scanner misuse, expose target
data, or compromise a user running the application. Use a
[private GitHub security advisory](https://github.com/Kousiksamanta1/VulnScan-Pro/security/advisories/new)
with the affected version, reproduction steps, impact, and a proposed fix when
available.

## Safe Use

- Scan only systems and networks you own or are explicitly authorized to test.
- Treat findings as indicators requiring manual verification.
- Protect saved scan history and exported reports.
- Do not attach sensitive reports, target details, or credentials to issues.
